## 1. 项目简介

Shogi-TransMaster 是一款专为**垂直领域视频**（尤其是日本将棋教学视频）设计的本地化自动化翻译工具。  
它将 **yt-dlp 下载 + Faster-Whisper 语音识别 + 大模型（DeepSeek-V3 / Gemini 1.5 Flash）翻译 + FFmpeg NVENC 硬编码** 全部集成在 Streamlit 可视化界面中，支持 **Human-in-the-Loop（人机协同）** 精修，最终输出高质量中字（或双语）视频。

## 3. 安装与启动

1. 克隆仓库
   ```bash
   git clone https://github.com/wanwande-sys/Shogi-TransMaster-NLP.git
   cd Shogi-TransMaster-NLP
   ```

2. 安装依赖
   ```bash
   pip install -r requirements.txt
   ```

3. 配置环境变量（`.env` 文件）
   - `SF_API_KEY=`（SiliconFlow DeepSeek 密钥）
   - `GEMINI_API_KEY=`（Gemini 密钥）
   - 代理端口默认 `7890`（可在 `config.py` 修改）

4. 启动程序
   - **Windows**：双击 `run.bat`
   - **Mac/Linux**：
     ```bash
     streamlit run app.py
     ```

启动后浏览器会自动打开 `http://localhost:8501`

## 4. 界面总览

程序分为 **3个主要 Tab** + **左侧侧边栏**：

- **Tab 1**：独立下载终端（仅下载视频+日文字幕）
- **Tab 2**：独立翻译压制（对已有本地视频进行翻译/重烧录）
- **Tab 3**：端到端流水线（下载→翻译→压制一键完成）

## 5. 侧边栏全局配置

- **当前视频类型**：切换领域预设（目前内置3种，默认为**♟️ 将棋专业解说**）
- **🧪 急速测试模式**：开启后仅处理前20句字幕，适合快速调试
- **📖 局部术语注入面板（仅将棋模式）**：实时编辑 `data/shogi_glossary.json`，支持动态添加专有名词

> 💡 **保存本地词库** 后立即生效，无需重启程序

## 6. Tab 1：独立下载终端

**功能**：批量下载 YouTube / Bilibili 等平台视频（支持单视频、播放列表、专栏）

**输入方式**：
- 直接粘贴链接（支持多行）
- 上传 `.txt` 文件（每行一个链接）

**下载配置**：
- 视频 + 日文字幕（标准工作流）← 推荐
- 纯音频提取（MP3 最高音质）

下载完成后视频路径会自动填入 Tab 2 的输入框。

---

## 7. Tab 2：独立翻译压制（最常用）

**适用场景**：
- 已有本地视频文件
- 需要二次精修字幕
- 想手动编辑字幕后再烧录

**操作流程**：

1. **视频路径**：可手动输入或点击**📁 浏览视频**按钮选择
2. **工作模式**：
   - **自动识别（听写翻译全流程）** ← 全新视频
   - **自由挂载/重压制** ← 已存在 `.zh.vtt` 时使用
3. **最终格式**：仅中文字幕 / 双语对照
4. **大模型引擎**：DeepSeek Pro（更准） / Gemini 1.5 Flash（更快）
5. **字幕排版与滤镜**：6种预设（含竖排、遮挡板、B站经典风等）
6. **基准字号**：建议 18-24（双语模式会自动缩小4号）

**自由挂载模式特色**：
- 支持直接上传 `.vtt` / `.srt`
- 自动读取同名 `.zh.vtt` 或 `生肉备份_Backup` 文件夹中的备份
- 提供**可视化精修台**（Data Editor），可直接在界面修改每一条字幕
- 修改后点击**🚀 确认烧录**即可使用 NVENC 硬件加速重新压制

## 8. Tab 3：端到端流水线（全自动）

适合**批量处理**多集视频：

- 输入链接 → 下载 → Whisper 识别 → 大模型翻译 → 烧录字幕 → 自动备份生肉
- 所有参数与 Tab 2 一致，支持并行处理播放列表

## 9. 将棋专属功能详解

### 9.1 动态领域字典注入
- 在侧边栏实时编辑 `shogi_glossary.json`
- 示例：
  - 日文：`7七金` → 中文：`7七金`
  - 日文：`打つ` → 中文：`打入`

### 9.2 专业 System Prompt
内置将棋专用提示词，强制模型：
- 使用标准坐标格式（**7七金** 而非 **77金**）
- 正确翻译“同”“成”“打入”等术语
- 保留手筋、定跡、王手等专业词汇

### 9.3 Whisper 提示词优化
预置了大量将棋关键词，提升识别准确率（如“藤井聡太”“居飛車”“1四歩”等）

## 10. 高级技巧与注意事项

- **生肉自动备份**：处理完成后原视频和 `.vtt` 会自动移动到 `生肉备份_Backup` 文件夹
- **竖排字幕**：预设 4️⃣ 和 5️⃣ 会自动智能断句（每16字强制换行）
- **硬件加速**：全程使用 `h264_nvenc` + CUDA，RTX 40系列压制速度极快
- **多行批量**：所有输入框都支持粘贴多行链接
- **临时文件清理**：程序会自动清理临时 `.vtt`，无需手动删除

## 11. 常见问题 FAQ

**Q：为什么下载不了视频？**  
A：请确认代理（7890端口）已开启且可用。

**Q：翻译结果出现“打字”“14步”怎么办？**  
A：1. 确保选择了“♟️ 将棋专业解说”预设；2. 在术语面板添加对应词条；3. 使用 Tab 2 的“自由挂载”模式手动修正后再烧录。

**Q：字幕太长溢出屏幕？**  
A：切换到“2️⃣ 强力遮挡板”或“3️⃣ 高位防挡区”预设，或调低字号。

**Q：想输出双语字幕？**  
A：在“最终格式”选择“双语对照”即可。

**Q：测试模式怎么用？**  
A：侧边栏开启“🧪 急速测试模式”，仅处理前20句，适合调试 Prompt 和词库。

## 12. 技术原理简述

- **ASR**：Faster-Whisper large-v3 + 领域专用 prompt
- **翻译**：DeepSeek-V3 / Gemini 1.5 Flash + 动态 glossary + 上下文连贯 Prompt
- **烧录**：FFmpeg + h264_nvenc 硬件编码 + 自定义 ASS 样式
- **UI**：Streamlit + pandas Data Editor 实现所见即所得精修
