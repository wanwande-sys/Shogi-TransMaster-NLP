# Shogi-TransMaster 使用说明书

## 项目简介

Shogi-TransMaster 是一个专注于垂直领域（尤其是日本将棋）视频的自动化翻译工具。  
它能帮助用户完成从视频下载、语音识别、日语翻译到中文字幕烧录的全流程，支持人机协同精修。

**核心目标**：降低将棋等小众领域视频的翻译难度，提高翻译准确率和效率。

---

## 主要功能

1. **Tab 1 - 独立下载终端**  
   - 支持单个或批量下载 YouTube、Bilibili 等平台的视频  
   - 支持下载视频 + 日文字幕（推荐）  
   - 支持纯音频提取（MP3）  
   - 支持播放列表和专栏下载

2. **Tab 2 - 独立翻译压制（最常用）**  
   - 对本地已有视频进行翻译和字幕烧录  
   - 两种工作模式：  
     - **自动识别模式**：自动语音识别 + 大模型翻译 + 烧录  
     - **自由挂载模式**：手动编辑字幕后重新烧录（推荐精修使用）  
   - 支持可视化字幕编辑（可直接修改每条字幕内容）  
   - 支持多种字幕样式（B站风格、遮挡板、竖排等）  
   - 支持仅中文字幕或双语对照  
   - 支持 DeepSeek Pro 和 Gemini 1.5 Flash 两种引擎

3. **Tab 3 - 端到端流水线**  
   - 一键完成“下载 → 识别 → 翻译 → 烧录”全流程  
   - 适合批量处理多集视频

---

## 将棋专属优化

- **动态术语词库**：可在侧边栏实时添加和编辑将棋专用词汇（如“7七金”“打入”等）  
- **专业提示词**：强制模型使用正确将棋记谱格式，避免“77金”“14步”等错误  
- **Whisper 优化**：内置将棋相关关键词，提升语音识别准确率

## 侧边栏功能详解（强烈建议先阅读）

侧边栏是使用本工具前必须正确配置的部分，直接影响翻译质量：

- **当前视频类型**  
  请选择 **♟️ 将棋专业解说 (带坐标纠正)** —— 这是将棋视频最准确的预设。

- **🧪 急速测试模式**  
  开启后仅处理视频前20句字幕，适合快速测试词库和翻译效果，推荐第一次使用时打开。

- **📖 局部术语注入面板（仅将棋模式）**  
  这是提升翻译质量的最重要功能。  
  - 你可以在这里实时添加或修改将棋专有名词和常用术语。  
  - 示例添加方式：
    - 日文： `7七金` → 中文： `7七金`
    - 日文： `打つ` → 中文： `打入`
    - 日文： `1四歩` → 中文： `1四歩`
    - 日文： `同` → 中文： `同`
  - 编辑完成后，**一定要点击“保存本地词库”** 按钮，词库才会生效。  
  - 词库文件保存在项目 `data/shogi_glossary.json` 中，积累得越多，翻译越准确。

**使用建议**：在翻译任何将棋视频前，先花2-3分钟在这里补充你视频中常见的术语。

## 如何使用本工具（推荐流程）

### 推荐流程一：单视频精校（最常用、高质量）

1. 在 **Tab 1** 下载你要翻译的视频（建议选择“视频 + 日文字幕”）
2. 切换到 **Tab 2**
3. 在左侧侧边栏：
   - 选择 **将棋专业解说** 预设
   - 开启测试模式（可选）
   - 在术语注入面板添加必要词汇并保存
4. 输入或选择视频文件路径（可点击“浏览视频”按钮）
5. 工作模式选择 **自由挂载/重压制**
6. 系统会自动加载字幕，出现可视化编辑表格
7. 在表格中逐条检查并修正翻译（重点修正坐标、术语等）
8. 设置：
   - 最终格式（仅中文字幕 或 双语对照）
   - 字幕排版样式
   - 大模型引擎
   - 基准字号
9. 点击 **🚀 确认烧录**，等待 NVENC 硬件加速完成压制
10. 成品视频会生成在同目录下，原文件自动备份

### 推荐流程二：批量自动处理

1. 在侧边栏配置好将棋预设和术语词库
2. 切换到 **Tab 3**
3. 在输入框粘贴多个视频链接（支持多行）
4. 设置输出格式和字幕样式
5. 点击 **🔥 启动批量自动化流水线** 即可自动运行

```bash

cd Shogi-TransMaster-NLP
pip install -r requirements.txt

# Windows 用户
run.bat

streamlit run app.py
