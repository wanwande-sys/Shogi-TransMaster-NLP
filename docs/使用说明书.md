## 1. 项目简介

Shogi-TransMaster 是一款专为**垂直领域视频**（如日本将棋、传统工艺）设计的自动化翻译工具。  
集成 **yt-dlp + Faster-Whisper + 大模型 (DeepSeek/Gemini) + FFmpeg NVENC**，支持 **HITL (人机协同)** 模式，解决小众领域“术语幻觉”痛点。

## 3. 安装与启动

### 3.1 环境初始化
```bash
# 1. 克隆仓库
git clone [https://github.com/wanwande-sys/Shogi-TransMaster-NLP.git](https://github.com/wanwande-sys/Shogi-TransMaster-NLP.git)
cd Shogi-TransMaster-NLP

# 2. 安装依赖
pip install -r requirements.txt
3.2 配置密钥
将根目录下的 .env.example 重命名为 .env，并填入以下内容：

代码段
SF_API_KEY="你的 SiliconFlow 密钥"
GEMINI_API_KEY="你的 Gemini 密钥"
3.3 启动程序
Windows: 双击 run.bat

Linux/Mac: streamlit run app.py

4. 界面总览
系统采用 Streamlit 构建，分为三大功能模块：

📥 独立下载终端：支持 YouTube/Bilibili 批量抓取。

🎛️ 独立翻译压制：对本地生肉进行 ASR 识别、LLM 翻译及 MTPE（译后编辑）。

🚀 全自动流水线：从链接到成品视频的一键式闭环。

5. 侧边栏全局配置
领域预设：切换不同场景的 System Prompt（如：♟️ 将棋专业解说）。

🧪 急速测试模式：仅处理前 20 句字幕，用于快速验证 Prompt 效果。

📖 术语注入面板：实时编辑 data/shogi_glossary.json。保存后立即生效。

6. 核心操作流程 (Usage)
6.1 译后编辑 (MTPE)
在 [Tab 2: 独立翻译压制] 中，系统提供可视化精修台：

锁定时间轴：左侧时间轴不可编辑，防止误触导致音画不同步。

双击编辑：直接修改右侧译文（如将 14步 修正为 1四步）。

同步更新：修改后点击 确认烧录，系统会先同步本地 .vtt 源码再启动压制。

6.2 字幕排版预设
内置 6 种滤镜样式：

B站风格：带标准阴影，适合各种背景。

强力遮挡板：带半透明背景，强制覆盖原片硬字幕。

真·竖排：专为将棋等传统文化设计，支持自动断句防溢出。

7. 将棋专属功能详解
坐标纠正：强制要求模型输出 7七金 格式，规避纯数字歧义。

语境对齐：精准识别 打入、成、手筋、詰み 等核心术语。

ASR 增强：通过 Whisper Prompt 注入藤井聪太、羽生善治等棋手名单，提升人名识别率。

8. 常见问题 FAQ
Q：为什么点击下载没反应？ A：检查代理端口。默认使用 127.0.0.1:7890，如使用其他端口请在 core/config.py 中修改。

Q：压制速度很慢？ A：系统默认调用 h264_nvenc 硬件加速。请确保显卡驱动已更新且支持 CUDA。

Q：翻译出现幻觉？ A：在侧边栏词库中添加该词条，开启测试模式运行 20 句，确认无误后再全量翻译。
